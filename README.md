# profile
안녕하세요.
자기소개서를 만들기 위한 저장소 입니다.

## 학습목표
Git 브랜치 전략으로 자기소개서 페이지를 만든다.
주제별로 파일을 생성
main에서 직접 수정하지 않고 개별 feature 브랜치 생성 후 작업
작업 후 올바르게 push 후 원격 반영
main<-feature 구조로 올바르게 Pull Request 생성 
변경 내용 설명, 체크리스트 등 PR 본문 충실히 작성
리뷰어 본인 지정 후 셀프 리뷰 절차 수행
file changed 코드 변경점 확인 후 셀프 리뷰 작성
Merge 정책 준수 , 안전하게 병합
여러 PR 중 순서를 고려하여 충돌예방

## 작업 계획
1. 저장소: 생성 및 README.md 작성
2. 이름: feature/name 브랜치 작업
3. 개요: feature/about 브랜치 작업
4. 기술 스택: feature/skills 브랜치 작업
5. 연락처: feature/contact 브랜치 작업
6. 추가 작업 후 push
7. PR 작성 
8. file changed 코드 확인 후 리뷰 작성
9. main <-- feature 병합

## 브랜치 전략
main최종 배포용 브랜치
feature/name 이름
feature/about 자기소개
feature/skills 기술
feature/contact 연락처
docs/readme Readme 수정
